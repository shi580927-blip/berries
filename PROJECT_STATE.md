## 2. ПРОДУКТ

### Название
- **«Безумные ягодки»**
- Подзаголовок: **«Лесное королевство»**

### Формат
- 2D casual match-3.
- Уровни ограничены ходами.
- Карта лесного королевства + магазин + маскоты + темы оформления.
- Первая платформа: **Яндекс Игры**.
- ПК + mobile landscape.
- Виртуальная сцена: **16:9, 1920×1080**.

### Цель
Красивый, понятный и залипательный match-3 с короткими сессиями, каскадами, яркими спецкомбинациями и мягкой добровольной монетизацией.

### Core loop
Карта → выбор уровня → цель/бустеры → match-3 → победа/поражение → награда/rewarded → карта → следующий уровень.

## 5. MATCH-3

### Поле
- Базово **8×8**.
- Архитектура позже должна позволять 7×8, 9×8 и маски/пустоты.

### Комбинации
- 3 — обычное удаление.
- 4 — линейный special.
- 5 — rainbow/universal.
- T/L — area bomb.

### Specials
- horizontal line;
- vertical line;
- bomb;
- rainbow.

**Внешние лучи, свечение, следы и взрывы не запекаются в special PNG — делаются кодом/FX.**

### Поведение
- swap только соседних клеток;
- невалидный swap откатывается;
- падение и refill сверху;
- автоматические каскады;
- если ходов нет — shuffle;
- лёгкий squash/bounce и juicy feedback.

## 6. ЦЕЛИ И УСЛОВИЯ УРОВНЯ

MVP цели:
1. собрать X ягод;
2. убрать лёд;
3. освободить/собрать жёлуди;
4. набрать очки.

Победа: обязательные цели выполнены до окончания ходов.

Поражение: ходы закончились раньше выполнения целей.

Rewarded после поражения: **+5 ходов**.

## 9. УРОВНИ

Первый релиз: **30 уровней**, data-driven через JSON.

Черновая дуга:
- 1–5: обучение + сбор ягод;
- 6–10: specials;
- 11–15: лёд;
- 16–20: жёлуди;
- 21–25: смешанные цели;
- 26–30: сложные комбинации целей/масок/лимитов.

Следующая задача проекта — превратить это в конкретную таблицу 1–30 с целями, ходами, набором ягод, препятствиями и сложностью.
