# Версии «Безумных ягодок»
Дата фиксации: 2026-10-15.

## Разделение
- `main` — существующая основная версия; при разделении не изменялась.
- `alpha` — сохранённая текущая альфа, исходный коммит `3b55807f81350e1b4eb57f725c03daca4691ca47`. Новые функции сюда не добавлять.
- `beta` — отдельная разработка от того же коммита. На момент создания игровой код полностью совпадает с альфой; добавлен только этот документ.
- VK/ОК — самостоятельная платформенная версия. В этом репозитории на момент проверки отдельной VK-ветки нет. Не подменять её Яндекс-сборкой. По предыдущим решениям адрес размещения: `https://berries.kingdom1.ru/vk/`; актуальность размещения в этой задаче не проверялась.

## Правила дальнейшей работы
1. Все новые согласованные правки выполнять в `beta`.
2. Не сливать beta в main/alpha автоматически. После проверки пользователь выбирает подходящий вариант.
3. VK адаптировать отдельной задачей после выбора основы — alpha или beta. Сохранить собственные SDK, рекламу, платежи и сохранения платформы.
4. Сборки beta именовать отдельно от alpha. Текущий workflow автоматически запускается только для main; ручная сборка beta должна явно выбирать beta.
5. При размещении beta для тестирования изолировать её сохранения от alpha (отдельный origin либо ключи сохранений); до этого не считать тестовый URL безопасно изолированным.
