## Ключевые решения
- GamePush подключать через BerriesPlatform adapter, без двойной загрузки нативных SDK. До интеграции закрыть общий i18n/схему сохранений; нынешний index RU и EN/TR-стенд не равны общему production-релизу.
- Проверять готовность игрока, lifecycle, изоляцию тестовых origins, единичную выдачу наград, восстановление покупок и каждый фактический платформенный контейнер. Общий checklist GamePush не отменяет требований Яндекса/VK/ОК.
- Прямая версия использует РСЯ ДЛЯ САЙТОВ; Яндекс Игры SDK и GamePush ради этого не нужны. Фактический host/модерация/свои ID обязательны.
- Rewarded РСЯ по умолчанию недоступен; нужен запрос поддержки. Для desktop Полноэкранного SD указан межстраничный сценарий: изменение Phaser-сцены не объявлять автоматически допустимым показом. Нельзя перезагружать игру ради имитации перехода.
- Fullscreen игры, fullscreen рекламы и поля16:9 — разные вещи. На iPhone проверять API, viewport/safe-area и предлагать запуск с экрана «Домой» при недоступности обычного fullscreen. Не обещать универсальное удаление браузерных/системных панелей или обрезать UI ради заполнения экрана.
- Утверждённые landscape1920×1080, FIT, логотипы/title, золотые заголовки и комбо<=2550мс сохраняются.

## Ближайшая последовательность
1. Общая готовая RU/EN/TR-точка входа/сохранения и отдельные allowlist-сборки.
2. GamePush: кабинет/площадки → init/lifecycle/язык → прогресс → реклама → отдельный платёжный gate.
3. Сайт: окончательный URL → fullscreen/standalone-оболочка → проверка iPhone → кабинет/форматы РСЯ → реклама и приёмка.
Работы двух провайдеров не смешивать; статус «чек-лист создан» не означает «SDK внедрён».
