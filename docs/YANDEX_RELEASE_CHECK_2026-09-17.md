# Ягодки — актуальная сверка перед Яндекс Играми

Дата: 2026-09-17.
Основа: универсальный документ «Кот Шеф — чек-лист Яндекс Игры» + актуальные требования Яндекс Игр.

## 1. Покупки — реализовано в коде, требуется проверка в черновике

Товары Королевской лавки:

- `coins_1000` — 1000 монет;
- `lives_5` — восстановление до 5 жизней;
- `boosters_3` — по 3 бустера каждого вида.

В коде уже предусмотрено:

- каталог через `payments.getCatalog()`;
- покупка через `payments.purchase()`;
- начисление награды только после успешной покупки;
- сохранение состояния до `consumePurchase()`;
- защита от повторного начисления одного purchase token;
- `payments.getPurchases()` при запуске для незавершённых покупок;
- остановка Gameplay API и общей паузы на время оплаты;
- отсутствие награды при отмене/ошибке.

Перед модерацией вручную:

- создать/активировать товары в Developer Console с точными ID;
- включить монетизацию покупками;
- проверить покупку в черновике;
- проверить сценарий: оплатить → до подтверждения обновить страницу → награда восстанавливается и покупка консумируется только после сохранения;
- проверить повторный запуск: одна покупка не начисляется дважды;
- проверить облачное восстановление покупки/баланса на другом устройстве.

## 2. Аудио — системный медиаплеер запрещён

Критичное требование чек-листа и модерации:

- на Android/iOS игра не должна создавать карточку системного медиаплеера в шторке;
- на desktop игра не должна регистрироваться в браузерном/системном медиаконтроле;
- игровая музыка и SFX должны воспроизводиться внутри игры через Web Audio / игровой audio manager, а не через обычный внешний/системный HTML media player;
- при потере фокуса весь звук должен остановиться;
- при fullscreen/rewarded рекламе должны остановиться и звук, и геймплей;
- после возврата не должно появляться двух параллельных музыкальных треков.

Текущее состояние реализации:

- SFX используют Phaser sound + Web Audio `AudioContext`;
- музыка загружается Phaser Loader и проигрывается через `scene.sound.add()`;
- единый `BerriesLifecycle` ставит сцены, таймеры/tweens и audio context на паузу при `blur`, `visibilitychange`, рекламе и покупке;
- SDK Gameplay API синхронизирован с общей паузой.

Это архитектурно соответствует требованию, но модерационный пункт считается закрытым только после ручной проверки на реальных устройствах/браузерах.

### Обязательная ручная проверка системного плеера

Android:
1. Запустить уровень с музыкой.
2. Открыть шторку уведомлений.
3. Убедиться, что карточки медиаплеера игры нет.
4. Свернуть приложение/перейти во вкладку — звук должен исчезнуть не позднее допустимого времени.

Desktop:
1. Включить системный медиаконтроль в Яндекс Браузере/Chrome.
2. Запустить игру с музыкой.
3. Убедиться, что игра не появляется в browser media controls.
4. Переключить вкладку/свернуть окно — звук должен остановиться.

## 3. Внешние ссылки в игре

Отдельный риск: в текущем экране музыкальных кредитов есть текстовые внешние URL (`incompetech.com`, ссылка Creative Commons). Перед release их нельзя оставлять как внешние ссылки/призывы к внешнему ресурсу.

Для игрового экрана кредитов использовать нейтральную локальную атрибуцию без кликабельных URL, например:

`Музыка: Kevin MacLeod — Incompetech. Лицензия: Creative Commons Attribution 4.0 International (CC BY 4.0).`

Полные источники, даты скачивания и URL хранить в `docs/LICENSES_AUDIO.md` как внутреннюю документацию проекта.

## 4. Что ещё не считать закрытым без ручного прогона

- системный медиаплеер Android/iOS/desktop;
- звук/геймплей при rewarded и покупке;
- console errors в черновике;
- Game Ready / Gameplay API в debug-панели Яндекса;
- чистый профиль без старого cache/localStorage;
- финальный ZIP;
- Android, iPhone/iPad и desktop;
- карточка, скриншоты, описание и лицензии.

## 5. Статус

Покупки и внутренняя аудио-архитектура уже заложены. До отправки на модерацию остаётся создать товары в консоли Яндекса, убрать внешние URL из игрового экрана кредитов и выполнить ручную матрицу тестирования.
