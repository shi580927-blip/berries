# Безумные ягодки — MVP для первого черновика

Версия: mvp-20260916-1. Сборка для проверки в черновике, не заявление о готовности к модерации.

## Изменения
- Платная лавка скрыта; её арт сохранён, реализация отложена. Магазин бустеров за монеты работает. В шапках монет/жизней вместо неработающих плюсов отображаются иконки ресурсов.
- Общая пауза с причинами: blur, скрытая вкладка, SDK-пауза, реклама. Ввод, сценовые таймеры, tweens, музыка и SFX приостанавливаются. Каскадные задержки ждут возобновления; busy не сбрасывается.
- Rewarded: один одновременный запрос, награда только onRewarded + onClose, ошибка/закрытие без просмотра не дают награду. На недоступную рекламу есть сообщение в результатах.
- Облако читается до первой игровой сцены; используется целая более новая копия по updatedAt, валюты не складываются. При замене локальная копия сохраняется в отдельном резервном ключе. Без дат выбирается удалённая только если в ней больше пройденных уровней. При ошибке чтения облачные записи заблокированы до следующего запуска. Локальные изменения сохраняются сразу, облачные объединяются с задержкой 3 секунды. Одновременная игра на двух устройствах не поддерживает слияние конфликтующих покупок: последняя копия побеждает.
- Победа показывает реальную награду, включая x2; поражение — фактические оставшиеся цели. Старые нарисованные значения закрыты непрозрачной панелью внутри арта. Игровой счёт остаётся в расчёте целей, отдельная плашка удалена.
- Настройка SFX сохраняется. Блокируются contextmenu/dragstart/selectstart и iOS callout в игровом поле.
- Язык SDK считывается. Единственный поддержанный язык этой сборки — русский, все неподдержанные языки получают RU. EN и перевод встроенных надписей в PNG не заявлять.
- Debug G, mapEditor, debugGrid и mockAds не активируются в production.
- Phaser 3.90.0 включён локально вместе с лицензией MIT. SDK /sdk.js остаётся платформенным.
- На стартовом экране добавлено управление.

## Что выбрать в черновике Яндекса
- Язык: русский. Платформы: ПК и мобильные, landscape. Телевизоры не заявлять.
- Загружать ZIP целиком, без дополнительной упаковки и внешней папки.
- Указать использование облачных сохранений. Реальные платежи пока не включать; rewarded использует SDK.
- Не отправлять сразу на модерацию: сначала открыть тестовую ссылку и проверить звук/паузу, рекламу, облачное восстановление и изображения.

## Как играть — текст для карточки
Меняйте соседние ягоды местами, нажимая на них по очереди. Собирайте три и более одинаковые ягоды в ряд и выполняйте цели слева за отведённое число ходов. Четыре ягоды создают полосатую спец-ягоду, пять — радугу, пересечение рядов — бомбу. Меняйте спец-ягоду с соседней, чтобы активировать её. Лёд снимается попаданиями, корни и жёлуди — совпадениями рядом или бустерами. Молоток действует на выбранную клетку, вентилятор очищает ряд, перемешивание меняет расположение ягод. Запас бустеров сохраняется между уровнями; пополняйте его за игровые монеты. После поражения можно добровольно посмотреть рекламу для +5 ходов, после победы — для удвоения монет. Выход без доигрывания не тратит жизнь.

## Остаток перед модерацией
1. Реальный прогон в черновике: первый запуск, 1→2, поздние уровни, special/лёд, win/lose, повторные входы.
2. Реклама: полный просмотр, отмена, недоступность; свернуть во время рекламы и вернуться.
3. Два устройства одного аккаунта: восстановление монет, уровней, бустеров; не тестировать параллельные покупки.
4. Android/iOS: размер кнопок, longtap, поворот, отсутствие системного плеера. ПК: правый клик, ресайз, потеря фокуса.
5. Актуальные скриншоты и карточка игры. Финальный баланс всех 30 уровней пока не подтверждён.

Платная лавка: в разработке, следующая доработка по запросу пользователя.
