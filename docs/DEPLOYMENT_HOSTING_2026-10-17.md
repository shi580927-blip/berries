## Следующая последовательность
1. На SprintHost проверить, что DNS-запись поддомена указывает на нужный сервер, в файловом менеджере назначен правильный каталог, а сертификат Let's Encrypt выпущен для `berries.kingdom1.ru` и реально работает на HTTPS.
2. Проверить HTTP 200 и SSL на `https://berries.kingdom1.ru/`, затем протестировать `/play/` после загрузки файлов. Пустая папка может отдавать 403/404 — это само по себе не доказывает, что поддомен настроен неправильно.
3. Для `/play/` сформировать чистый SDK-free build без dev/QA файлов; `index.html` находится **прямо внутри /play/**. Относительные ссылки `styles.css`, `src/*`, `assets/*`, `audio/*`, `vendor/*` должны загружаться из этого каталога.
4. Реализовать browser fullscreen по пользовательскому нажатию там, где поддерживается, и standalone PWA для Safari/iPhone там, где браузерный Fullscreen API недоступен. Landscape 1920×1080 FIT, без обрезания игрового интерфейса. См. `docs/KINGDOM1_RSYA_FULLSCREEN_CHECKLIST.md`.
5. До регистрации домена в РСЯ и получения **реальных** рекламных block ID реклама и rewarded не считаются включёнными. Не интегрировать SDK Яндекс Игр в веб-версию.
6. Для `/vk/` сначала отдельная ветка `platform/vk-ok`, адаптер VK и матрица тестов ОК; не публиковать просто скопированный `/play/`.
7. Изолировать ключи прогресса по платформам: `/play/` и `/vk/` имеют **общий origin/localStorage** несмотря на разные папки. Общее сохранение возможно только как осознанная схема или проверенная миграция.
