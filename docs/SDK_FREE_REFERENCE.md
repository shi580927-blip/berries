## Границы эталона

Это SDK-free база с local-адаптером. Яндекс/VK/ОК/GamePush SDK, реальные реклама и платежи здесь не подключены. Русская тестовая версия обновлена общей базой; историческая рабочая RU с SDK не менялась.

EN/TR ещё используют отдельный тестовый bootstrap и изолированные сохранения по языку. Это не завершённая общая RU/EN/TR production-сборка. Ручной выбор языка/общий прогресс и release allowlist общей сборки — следующий этап. Изоляцию тестового storage не переносить в окончательную игру.

Проверены Node-тесты, пиксельная геометрия/alpha16файлов, браузерные EN/TR сценарии desktop и Android-эмуляции, реальные обработчики win/lose и переходы next/retry/map. Основное сохранение не изменено. Физический Android, полный последний swap/каскад и баланс всех30уровней не проверены.

Изолированный localhost Chromium: startupReady RU main3,396–3,602s, новый EN3,760–4,181s, TR3,677–3,996s. Это не обещание скорости на устройстве пользователя. Минутный запуск пользователя не воспроизведён. Был ранний TR-timeout60s в многопроцессном прогоне; успешный повтор не доказывает отсутствия проблемы.

При прямом создании результатов нет новых запросов/рисования золотых заголовков, JS занимает десятки миллисекунд. Полная видимость победы через реальный обработчик в software Chromium занимала2,298/3,773s; поражения0,781/0,942s. Этот предел не объявляется исправленным. Дальнейшее профилирование кадров/телефона вести от эталона, сохраняя утверждённый вид.
