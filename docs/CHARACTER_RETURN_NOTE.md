# Возврат к персонажам после ассетов

Статус: ОТЛОЖЕНО ДО ЗАВЕРШЕНИЯ ОСНОВНЫХ АССЕТОВ.

После того как будут закрыты игровые ассеты (ягоды, спецэлементы, препятствия, бустеры, кнопки уровней, базовые UI-элементы и фон), обязательно вернуться к персонажам.

Последние версии персонажей пользователю понравились. Их считать предпочтительным направлением для дальнейшей доработки.

Зафиксированные правила персонажей:
- милый, забавный premium-casual стиль;
- крупные выразительные глаза;
- открытые глаза — синие;
- в коронах оставлять только один центральный камень;
- не менять утверждённый состав семьи без отдельного решения;
- основа семьи — первый семейный пак, но принцесса заменяется утверждённой принцессой из второго пака; других персонажей из второго пака не брать.

Следующее действие после завершения ассетов: подготовить финальные отдельные master-ассеты персонажей и эмоций на прозрачном фоне.
