# Главная страница поддомена «Безумные ягодки»
Дата решения: 2026-10-17

## Назначение
- `https://berries.kingdom1.ru/` — компактный лендинг конкретной игры, не копия сайта Mintyberries Games.
- `https://berries.kingdom1.ru/play/` — работающая SDK-free версия игры; не перемещать и не менять при установке лендинга.
- `https://kingdom1.ru/` — основной сайт студии и других игр.
- `/vk/` — отдельная интеграция VK/ОК в дальнейшем. `/vkplay/` отложена.

## Первый лендинг
Подготовлена отдельная HTML-страница, не загружающая Phaser/SDK/РСЯ; у неё есть кнопки «Играть бесплатно» → `/play/`, описание и правила, ссылки на сайт студии. Используются существующие изображения по путям `/play/assets/ui/panels/logo_main.png` и `/play/assets/web/backgrounds/background_title_forest.webp`. Никакие дополнительные большие изображения не копируются.

Артефакт для владельца — ZIP с одним корневым `index.html`. **Это файл на загрузку через SprintHost, а не публикация на домен из GitHub.** Статус: создан файл, факт его установки и доступность главной страницы не проверены.

## Инструкция для SprintHost
1. В панели SprintHost найти *корень документов именно поддомена* `berries.kingdom1.ru`, в котором расположена папка `play/`.
2. Разархивировать содержимое ZIP (единственный файл `index.html`) в **корень поддомена, рядом с `play/`**, а не внутрь `play/`.
3. Если там уже есть `index.html` или `index.php` как заглушка хостинга, сначала сохранить резервную копию и проверить порядок обработки индексных файлов.
4. Проверить `https://berries.kingdom1.ru/`: загрузка логотипа/фона из `/play/assets/`, кнопка ведёт на `/play/` и запускает рабочую игру.
5. Перед подключением РСЯ нужны настройки/модерация сайта, политика конфиденциальности и релевантные реквизиты; текущая HTML-страница не подключает рекламу.

Основные ветки `main`, `base`, `reference/sdk-free-2026-10-16` не менять.
