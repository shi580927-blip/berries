# Расширение контента — 16.10.2026

## Принято пользователем
Одна локация — 20 уровней. Диапазоны: 1–20 / 21–40 / 41–60. Глобальные номера стабильны: старые уровни21–30 не удаляются и не становятся1–10. Новые настройки уровней добавляются после30.

## Что реализовано в структуре
В campaign.js: LEVELS_PER_LOCATION=20, locationForLevel(level), locationId в каждой конфигурации уровня, MAX_LEVEL из реально существующих LEVELS. Ограничения сохранения/unlocked и следующий уровень больше не используют константу30. Наличие диапазона до40/60 не создаёт несуществующие уровни31–60.

data/content-packs.json описывает локации, пути карт/фонов и политику пакетов. Пустые пути означают отсутствие нового арта, не скрытую подмену старой картой.

## Что ещё предстоит
Текущий renderer карты всё ещё показывает прежние30 точек. Разделить его на страницы по20 нужно при подключении навигации между локациями; точки21–30 нельзя просто скрыть до реализации перехода. Сейчас новая схема метаданных не меняет вид карты. Загрузчик пакетов по требованию ещё не реализован. Каталог подготовлен как контракт, пока не загружается runtime и не входит в release allowlist; включить его при интеграции загрузчика.

## Герои, спецягоды, анимации, инапы
Каждый будущий heroPack имеет устойчивые id, productId, specialBerryId, animationSetId и assetManifest. Графика/анимации героя отделены от пакета языка; тексты локализуются по ключам. Общие ягоды/фон не дублируются в каждом герое.

Предлагаемый тип товара — постоянное открытие героя (non-consumable); это архитектурное предположение, не утверждённый каталог продаж. Расходы на применение способности, заряд, перезарядка, эффект спецягоды и баланс задаются отдельно для каждого героя до реализации.

Оплата и владение отделены от загрузки: покупку подтверждает адаптер площадки, затем владение сохраняется/восстанавливается и сверяется с платформой. Нельзя выдавать платного героя лишь по значению localStorage, повторно покупать уже открытого героя или применять к нему consumePurchase расходуемых товаров. Существующие coins_1000/lives_5/boosters_3 остаются расходуемыми и не меняются. Для собственного сайта потребуется отдельная проверка оплаты на сервере, если там будут покупки.

Загружать активного героя; остальных — только при явном предпросмотре/выборе. До успешной загрузки и проверки владения переключение не завершать, при ошибке сохранять прежнего героя. Возврат на карту/смена языка/локации не должны терять героя или прогресс.

GamePush и самостоятельный сайт используют общую игру, отдельные адаптеры языка/покупок/сохранений. GamePush SDK и новые продажи на этом этапе не подключались; конкретные API проверять по официальной документации во время интеграции.

## Проверки
Тест границ1/20/21/40/41, существования ровно30 текущих уровней, сохранности completed1–30, монет и бустеров. Существующие campaign/i18n/platform проверки выполняются после изменения. Визуальных изменений карты сейчас нет; браузерная проверка расширения ещё не выполнена.
