## Новая архитектура
- `src/gameplay_cycle_3_core.js`: чистые правила и моделирование падения. Независимы от Phaser и от SDK, пригодны для Node-тестов.
- `src/gameplay_cycle_3_runtime.js`: Phaser-интеграция поверх `runtime_stable_v10.js`, без изменений платформенных файлов.
- `src/royal_trail.js`: расширяемая структура сюжетных участков. Пагинация вычисляется из числа уровней, без ограничения 20/30.
- `src/campaign.js`: только новые **необязательные** свойства конфигураций; ключ и структура пользовательского сохранения не менялись.
- `tests/gameplay-cycle-3.cjs`: падение, выход, перегородки, допустимые ходы, сохранения, зоны.
- `tests/gameplay3-browser.cjs`: smoke для реальной Phaser-сцены на уровнях 6, 10, 12.

## Важно по реализации и ограничениям
- Лёд (включая 2 слоя) и корни работают прежней механикой, валун — другой тип неподвижного блока (1–2 HP).
- Жёлуди на 6/7/10 перемещаются вертикально вместе с гравитацией; цель засчитывается только при выходе внизу.
- Безумие выбирает только соседние свободные ягоды и запускается после основного каскада. Количество попыток: 1 / 2 / 3, максимум 3 на ход. Базовый резолвер сохраняет лимит 24 каскадов и проверку ходов.
- Валун теперь использует **утверждённый прозрачный атлас** `assets/blockers/boulder_atlas_game.png` + JSON: целый (2 HP), треснувший (1 HP), не блокирующие каскад осколки, пыль и мох. Прежние Phaser Graphics оставлены только как защитный fallback, если текстура недоступна.
- Восемь пользовательских GIF героев сохранены отдельно в `art/source_animations/royal_trail/`; для будущих кат-сцен собран оптимизированный **64-кадровый атлас WebP+JSON** в `assets/characters/royal_trail/`. **Пока НЕ включён в игровой релиз и не назначен героям** до ручного согласования ролей/таймингов.
- Сюжетные реплики на карте не блокируют игру. Тема спецягод пока ограничена цветовой подачей искр; силы и платных преимуществ нет.
- Старая карта 30 точек и пользовательская ручная расстановка сохранены. Метаданные тропы расширяемы, но полный процедурный визуальный рендер/многоэкранная карта ещё не внедрены.
- Все платформенные SDK выключены (локальный adapter `src/platform/local.js`). `main`, `base`, публичный kingdom1.ru не трогать.
- Комбо 2,55 секунды не меняли. Никакие эффекты не вводят дополнительной обязательной задержки перед следующим ходом.

## Запуск пользователем
В GitHub Desktop выберите `feature/gameplay-cycle-3`, нажмите **Fetch origin → Pull origin**, затем откройте репозиторий в VS Code и запустите **Live Server** на `index.html` (обычно `http://127.0.0.1:5501/` при сохранённой настройке). В вашем локальном репозитории должен быть `vendor/phaser.min.js`. Если файла нет после чистого клонирования, откройте терминал VS Code и выполните `node scripts/setup-local.cjs` (загрузит закреплённый Phaser 3.90.0); альтернативно распакуйте тестовый ZIP из GitHub Actions, в нём Phaser уже включён.

**Сначала испытать уровни 6, 7, 8, 10 и 12**, затем 16–18 для сравнения старой механики. Не использовать существующие сейвы как единственную копию: можно протестировать во втором браузерном профиле.

## Приёмка и дальнейшие шаги
Программатические тесты и сборка — автоматизированы GitHub Actions. Только после ручного игрового прохода принять баланс ходов и окончательный арт. Следующие этапы: полная модульная карта с прокруткой/страницами, согласованное включение геройских анимаций, проверка нового валуна на телефонах, баланс 11–30 и стресс-тест автоперемешивания.
