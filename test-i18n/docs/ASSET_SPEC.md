# ASSET_SPEC — «Безумные ягодки: Лесное королевство»

Версия: 0.1
Дата: 2026-09-13
Статус: рабочая спецификация до начала разработки

## 1. Общие правила игровых ассетов

- Все элементы клетки готовятся на квадратном холсте 1:1.
- Мастер-размер игровых фишек и препятствий: 512×512 px.
- Формат мастер-файлов: PNG-32 / RGBA / sRGB.
- Фон: прозрачный, кроме фонов локаций.
- В Phaser ассеты масштабируются только пропорционально; растяжение по одной оси запрещено.
- Без текста, цифр и надписей внутри игровых ассетов.
- Мягкая тень допустима только внутри границ PNG.
- Визуальный центр и точка посадки должны быть одинаковыми внутри одной группы ассетов.

- клубника остаётся вытянутой, малина/морошка сегментированными, черника круглой, крыжовник овальным с прожилками, ежевика тёмной сегментированной;
- квадратным является холст, а не сам объект;
- selected/highlight желательно делать программным FX, а не отдельной картинкой.

## 3. Лёд — overlay

### 3.1. Принцип
Лёд не является содержимым клетки. Он рисуется отдельным верхним слоем поверх ягоды или жёлудя.

### 3.2. Файлы
| Файл | Мастер | Заполнение | Прозрачность центра | Края/блики |
|---|---:|---:|---:|---:|
| assets/blockers/ice_1.png | 512×512 | 94–98% | ~25–45% opacity | ~60–85% |
| assets/blockers/ice_2.png | 512×512 | 94–98% | ~40–60% opacity | ~75–95% |

Требования:
- одинаковый внешний силуэт и одинаковая посадка `ice_1` и `ice_2`;
- содержимое клетки должно быть узнаваемо через лёд;
- `ice_2` визуально толще, мутнее, с большим количеством инея и трещин;
- без внешней тяжёлой тени;
- переход `ice_2 → ice_1 → none` не должен визуально прыгать.

## 8. Персонажи

Мастер для каждой позы: 1024×1024 PNG RGBA, прозрачный фон.

Канон:
- милый casual-стиль из утверждённого экрана «Почти получилось!»;
- открытые глаза — синие;
- в короне используется только один центральный камень;
- Король и Королева — основные маскоты;
- состав семьи: основа первого семейного пака, но принцесса заменяется на утверждённую принцессу из второго пака; остальные персонажи второго пака не используются.

Минимальные состояния маскотов MVP:
- idle;
- happy;
- sad;
- point/invite.

Дополнительно позже:
- win/celebrate;
- surprised.

## 9. Фоны

Мастер-фон: 1920×1080, 16:9.

Минимум для MVP:
- `assets/themes/forest/game_bg.jpg` — игровая лесная поляна;
- `assets/themes/forest/map_bg.jpg` — карта уровней;
- `assets/themes/forest/menu_bg.jpg` — главное меню;
- `assets/themes/royal_garden/game_bg.jpg` — премиальная тема позже в текущем MVP-плане.

Фон не должен конкурировать с полем по контрасту. Центр/зона поля — спокойнее, края — декоративнее.

## 12. Definition of Done для ассета

Ассет считается готовым, если:
- соответствует указанному мастер-размеру;
- имеет правильный альфа-канал;
- не содержит текста/цифр, если это не UI-текст;
- не обрезан по краям;
- сохраняет пропорции при уменьшении;
- читается в реальном игровом размере на мобильном landscape;
- визуально согласован с остальными элементами группы;
- имя файла соответствует спецификации.
