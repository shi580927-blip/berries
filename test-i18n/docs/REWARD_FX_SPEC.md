## Комбо
Комбо должно заполнять экран, быть плотным, ярким, сочным и давать ощущение награды. Редкие и бледные частицы отвергнуты. По последнему уточнению надписи должны оставаться полупрозрачными, а частицы — яркими. Не уменьшать частоту эффектов ради продления времени показа. Ходы/каскады не блокировать.

Текущая правка: вернули gap220ms вместо1100ms, центральное слово alpha=.70/.78, боковые .50–.55; целые боковые слова обмениваются позициями по двумерным кривым, не по горизонтальной линии; основное слово3150ms + задержка по буквам, боковые слова2980ms + разнос. Затухание alpha через Expo.in, чтобы эффект не исчезал визуально сразу.100+16*chain конфетти (максимум180),28+5*chain звёзд (максимум53), непрозрачные, конфетти крупнее и по большей площади экрана. Время частиц2.6–3.55с. Лимит живых FX повышен160→700, добавлено снятие destroyed-объектов из Set. Это реализация для просмотра, ещё не пользовательское утверждение.

Риск: плотные наложения нужно проверить на физическом Android/FPS; если требуется оптимизация, использовать пулы/эмиттеры и атласы, сохраняя плотность и длительность, а не обедняя награду. Не допускать накопления объектов после смены сцены.
