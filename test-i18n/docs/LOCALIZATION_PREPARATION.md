## Терминология и вычитка
- Один бустер fan сейчас назван в разных местах «Веер» и «Вентилятор». В словарях один предмет: Fan / Vantilatör; при подключении унифицировать русскую подпись с учётом фактической иконки.
- Монеты: EN coins, TR altın — короткая игровая подпись; числовые суммы остаются параметрами.
- Cloudberry: TR Kutup böğürtleni — черновой термин; проверить носителем перед публикацией. Не подменять картинку другой ягодой.
- Спецягоды: Striped / Çizgili, Bomb / Bomba, Rainbow / Gökkuşağı.
- Для TR проверить ı/İ/ş/ğ/ç/ö/ü, особенно верхний регистр, вместо механического ASCII upper-case использовать locale-aware подход.
